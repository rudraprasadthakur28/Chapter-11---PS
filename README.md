# Python Chapter 11 Practice Set

This repository contains solutions to the Python Chapter 11 Practice Set.

The practice set focuses on advanced Object-Oriented Programming concepts such as inheritance, property decorators, operator overloading, and special methods.

## Practice Problems

### 1. 2-D and 3-D Vectors

Create a class representing a 2-D vector and use it to create another class representing a 3-D vector.

### 2. Inheritance

Create a class `Pets` from a class `Animals` and further create a class `Dog` from `Pets`.

Add a `bark()` method to the `Dog` class.

### 3. Property Decorator

Create a class `Employee` with `salary` and `increment` properties.

Write a `salaryAfterIncrement` method using the `@property` decorator and a setter to change the value of `increment` based on the salary.

### 4. Complex Numbers

Create a class `Complex` to represent complex numbers.

Overload the `+` and `*` operators to add and multiply complex numbers.

### 5. Vector Operations

Create a class `Vector` representing a vector of `n` dimensions.

Overload the `+` and `*` operators to calculate:

- Sum of two vectors
- Dot product of two vectors

### 6. `__str__()` Method

Write the `__str__()` method to display a 3-dimensional vector in the following format:

```text
7i + 8j + 10k
```

### 7. `__len__()` Method

Override the `__len__()` method on the vector class from Problem 5 to display the dimension of the vector.
